# Building-Energy-Intelligent-MOS 接口协议规范（V1）

## 1. 协议总则

- 基础地址：`http://<host>:8080`
- 传输协议：HTTP/1.1
- 编码：UTF-8
- 时间格式：ISO-8601（示例：`2026-03-18T13:00:00`）
- 鉴权：当前版本无鉴权（内网演示模式）

## 2. 响应规范

### 2.1 标准业务响应（Energy/Statistics/MCP）

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

- `code=0` 表示成功
- `code=1` 表示失败

### 2.2 错误响应

```json
{
  "code": 1,
  "message": "错误信息",
  "data": null
}
```

- 参数/业务错误：HTTP 400
- 服务内部错误：HTTP 500

### 2.3 非标准响应

以下接口不使用标准壳：
- `GET /api/report/export`：返回 `text/csv`
- `POST /api/ai/chat`：返回 `text/event-stream`
- AI 其余部分：直接返回对象/数组（无 `code/message/data`）

## 3. 字段与单位约定

- `electricityKwh`：电耗，单位 `kWh`
- `waterM3`：水耗，单位 `m³`
- `hvacKwh`：空调能耗，单位 `kWh`
- `hvacSupplyTemp/hvacReturnTemp/envTemperature`：单位 `℃`
- `humidity`：单位 `%`
- `occupancyDensity`：单位 `人/100㎡`
- `deviceStatus`：`NORMAL` 或 `ABNORMAL`
- `granularity`：`hour | day | month`

## 4. Energy 模块

### 4.1 获取建筑列表

- 方法：`GET`
- 路径：`/api/energy/buildings`

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": 1,
      "buildingCode": "BLD-A01",
      "buildingType": "办公",
      "buildingName": "总部办公楼A",
      "area": 23500.00
    }
  ]
}
```

### 4.2 获取设备列表

- 方法：`GET`
- 路径：`/api/energy/devices`
- Query：`buildingId`（可选）

### 4.3 新增能耗记录

- 方法：`POST`
- 路径：`/api/energy/records`
- Body：`application/json`

请求示例：

```json
{
  "buildingId": 1,
  "deviceId": 1,
  "recordTime": "2026-03-18T10:00:00",
  "electricityKwh": 128.5,
  "waterM3": 22.1,
  "hvacKwh": 88.3,
  "hvacSupplyTemp": 8.5,
  "hvacReturnTemp": 13.1,
  "envTemperature": 24.0,
  "humidity": 45.0,
  "occupancyDensity": 62.0,
  "deviceStatus": "NORMAL"
}
```

### 4.4 更新能耗记录

- 方法：`PUT`
- 路径：`/api/energy/records/{id}`
- Body 同 4.3

### 4.5 查询能耗记录

- 方法：`GET`
- 路径：`/api/energy/records`
- Query：
- `buildingId` 可选
- `deviceId` 可选
- `startTime` 可选
- `endTime` 可选
- `deviceStatus` 可选
- `page` 可选，默认 `0`
- `size` 可选，默认 `50`

响应 `data` 为分页对象，核心字段：`content,totalElements,totalPages,size,number`

### 4.6 CSV 导入

- 方法：`POST`
- 路径：`/api/energy/import/csv`
- Content-Type：`multipart/form-data`
- 字段：`file`

CSV 列顺序：
`buildingId,deviceId,recordTime,electricityKwh,waterM3,hvacKwh,hvacSupplyTemp,hvacReturnTemp,envTemperature,humidity,occupancyDensity,deviceStatus`

## 5. Statistics 模块

### 5.1 时段汇总

- 方法：`GET`
- 路径：`/api/statistics/time-summary`
- Query：`buildingId,start,end,granularity`

响应 `data` 元素：

```json
{
  "timeBucket": "2026-03-18",
  "electricityKwh": 1024.6,
  "waterM3": 212.7,
  "hvacKwh": 702.2
}
```

### 5.2 COP 统计

- 方法：`GET`
- 路径：`/api/statistics/cop`
- Query：`buildingId,start,end,granularity`

响应 `data` 元素：

```json
{
  "timeBucket": "2026-03-18",
  "cop": 1.2375
}
```

### 5.3 异常分析

- 方法：`GET`
- 路径：`/api/statistics/anomaly`
- Query：`buildingId,start,end`

响应 `data` 元素：

```json
{
  "recordId": 1001,
  "recordTime": "2026-03-18T09:00:00",
  "electricityKwh": 265.1,
  "zScore": 3.42,
  "changeRate": 0.51
}
```

## 6. Report 模块

### 6.1 导出统计报表

- 方法：`GET`
- 路径：`/api/report/export`
- Query：`buildingId,start,end,granularity`
- 响应：`text/csv`
- 响应头：`Content-Disposition: attachment; filename=energy-report.csv`

## 8. AI 模块

## 8.1 同步问答

- 方法：`POST`
- 路径：`/api/ai/chat/sync`
- Body：

```json
{
  "conversationId": "frontend-demo",
  "question": "请分析今日能耗异常原因",
  "useKnowledgeBase": true
}
```

响应示例：

```json
{
  "conversationId": "frontend-demo",
  "answer": "...",
  "sources": ["hvac-manual.md", "maintenance-guide.md"]
}
```

## 8.2 流式问答（SSE）

- 方法：`POST`
- 路径：`/api/ai/chat`
- Content-Type：`text/event-stream`
- 事件类型：`token | source | done | error`

## 8.3 会话管理

- `GET /api/ai/conversations`
- `GET /api/ai/conversations/{id}/history`
- `DELETE /api/ai/conversations/{id}`

## 8.4 知识库管理

- `POST /api/ai/knowledge/upload`（multipart: `file` + 可选 `title/category`）
- `GET /api/ai/knowledge/documents`
- `DELETE /api/ai/knowledge/documents/{id}`
- `POST /api/ai/knowledge/reindex/{id}`

## 9. 联调建议

- 前后端统一使用本文件字段名，不做同义字段映射。
- AI 模块当前返回风格与标准壳不同，前端需单独处理。
- 后续若要统一协议，建议将 AI 模块也收敛到 `ApiResponse<T>`。
